# ランタイムシナリオ

自分専用の AI 会話コンソールで、DEN さんがたどる操作とその結果を、実際に動かして観察できる形で書いたジャーニーです。
実行と証拠の取得は共有ランタイム検証が担当します。

**前提** — 工場の検証では、毎回新しい空の会話の記録と、決まった応答を返す偽の応答役を指定してアプリを起動します。本物の AI は呼びません。偽の応答役は、直前の発言と、その会話でのそれまでの往復の数を入れた応答を返します（1 往復目なら 1、2 往復目なら 2）。画面での観察に加えて、画面が使う JSON の API で同じ結果を確かめてもかまいません。

## 1. 起動すると 3 つの領域が見え、サーバの状態がすべて正常になる

1. 空の会話の記録と偽の応答役を指定してアプリを起動し、ブラウザでトップページを開きます。
2. 会話の領域、履歴のサイドメニュー、サーバの状態のメニューの 3 つが表示されていることを確認します。
3. 履歴のサイドメニューに、会話がまだ 1 件も無いことが分かる表示が出ていることを確認します。
4. サーバの状態のメニューを開き、「アプリ自身」「AI への接続」「会話の記録」の 3 項目が表示され、3 つとも「正常」であることを確認します。

**失敗条件** — 3 つの領域のどれかが無い、会話が無いのに履歴が空白のまま何も示さない、状態の項目が 3 つ揃わない、またはどれかが「正常」でない。`/health` や `/build-id` が 200 以外を返す、またはリダイレクトする。

## 2. AI と 2 往復し、2 回目の応答に前のやり取りが反映される

1. 起動したアプリで新しい会話を始め、`私の好きな果物はびわです` と送ります。
2. 会話の領域に、自分の吹き出し（送った文）と AI の吹き出しが、この順に並ぶことを確認します。2 つは見分けられる形（位置、色、話者の表示など）になっており、AI の吹き出しは空ではなく、往復の数 1 が入った応答の全文が一度に表示されています。
3. 同じ会話で続けて `私の好きな果物は何ですか` と送ります。
4. 吹き出しが合わせて 4 つ、自分・AI・自分・AI の順に並び、2 回目の AI の応答に、直前の発言 `私の好きな果物は何ですか` と往復の数 2 が入っていることを確認します。

**失敗条件** — AI の吹き出しが空、または自分の吹き出しと見分けられない。吹き出しの順序が入れ替わる、同じものが重複する。2 回目の応答の往復の数が 1 のまま（前のやり取りが AI に渡っていない）、または直前の発言が入っていない。応答が途中までしか表示されない。

## 3. 再起動しても会話が残り、履歴から開き直して続きを話せる

1. 起動したアプリで新しい会話を始め、`りんごの話` と送って応答を受け取ります。
2. もう 1 つ新しい会話を始めます。会話の領域が空になることを確認し、`みかんの話` と送って応答を受け取ります。
3. アプリを再起動し、トップページを開き直します。
4. 履歴のサイドメニューに会話がちょうど 2 件、新しい順（`みかんの話` の会話が上、`りんごの話` の会話が下）に並び、どちらの会話か見分けられることを確認します。
5. `りんごの話` の会話を選びます。それまでのやり取り（自分の吹き出しと AI の吹き出しの 2 つ）が会話の領域に表示されることを確認します。
6. その会話で `続きです` と送ります。応答の往復の数が 2 になり、履歴の件数は 2 件のまま、`りんごの話` の会話が一番上に移ることを確認します。
7. もう一度アプリを再起動し、`りんごの話` の会話を開いて、吹き出しが 4 つ（2 往復分）すべて残っていることを確認します。

**失敗条件** — 再起動後に会話やメッセージの一部が消える（メモリにしか無い、書き込む前に応答が返る）。履歴が古い順に並ぶ、件数が合わない、どの会話か見分けられない。開き直した会話に別の会話のやり取りが混ざる。続きを送ると、同じ会話に加わらずに新しい会話が増える。

## 4. AI に繋がらないとき、状態で分かり、送ったメッセージが残る

1. 空の会話の記録と、AI に繋がらない設定を指定してアプリを起動し、ブラウザで開きます。
2. サーバの状態のメニューで、「AI への接続」だけが「異常」になり、「アプリ自身」と「会話の記録」は「正常」のままであることを確認します。
3. 新しい会話で `繋がりますか` と送ります。
4. 会話の領域に、AI に繋がらないことが分かる表示が出て、自分が送った `繋がりますか` が会話の領域に残っていることを確認します。入力し直さずに済む状態です。

**失敗条件** — AI に繋がらないのに「AI への接続」が「正常」になる、または他の 2 項目まで「異常」になる。送ったメッセージが消える、空の AI の吹き出しや応答らしい文が出る、または何も表示されずに止まる。
