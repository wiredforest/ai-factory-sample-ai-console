## 1. なぜ今か

本物の AI と Web Search を手元で使ってみると (2026-11-24)、AI の応答は Markdown (見出し・箇条書き・`**強調**` など) で書かれてくることが多い。今の画面は応答をそのままの文字で出すので、`**天気**:` や `- ` が記号のまま並び、読みにくい。AI の応答の Markdown を解釈して、簡単に装飾して表示したい。

一方で、AI の応答には Web から拾った文が混ざる。応答を HTML として扱うと、スクリプトが動いたり、外部へ通信したりする入口になる。装飾は、安全を崩さない範囲に限る。

## 2. 実装フェーズとユーザーストーリー

### フェーズ 6 — 応答の Markdown の表示

- **S16 AI の応答の Markdown を、装飾して読める**: DEN さんとして、AI の応答に含まれる Markdown を、記号のままではなく装飾された形で読みたい。長い応答でも構造がひと目で分かるように
  - 受け入れ条件: AI の応答の吹き出しで、次の書式を解釈して表示する。見出し (`#`〜`######`)、段落 (空行で分ける) と段落の中の改行、箇条書き (`-`・`*`・`+`)、番号付きの箇条書き (`1.` など)、強調 (`**x**`・`__x__`)、斜体 (`*x*`・`_x_`)、打ち消し線 (`~~x~~`)、インラインのコード (`` `x` ``)、コードブロック (```` ``` ```` で囲む)。箇条書きの入れ子 (字下げ) は、少なくとも 1 段は分かる形で出す
  - 受け入れ条件: 上に挙げていない書式 (表、引用、画像、水平線、HTML のタグなど) は解釈せず、書かれたままの文字で出す。文字を黙って消さない
  - 受け入れ条件: リンク `[文字](URL)` は、クリックできるリンクにせず、「文字 (URL)」のように URL をそのまま文字で出す。本文に直接書かれた URL も文字のまま。画像 `![説明](URL)` は読み込まず、書かれたままの文字で出す。どの場合も、画面を表示しただけで外部へ通信が起きない
  - 受け入れ条件: 自分の発言の吹き出しは、今と同じく打ったとおりの文字で出す (解釈しない)
  - 受け入れ条件: 記録には応答の原文を残し、表示するときに解釈する。記録の形は変えない。フェーズ 6 より前の会話も、開き直すと装飾されて見える
  - 受け入れ条件: 閉じていないコードブロックや、対になっていない `**` などの崩れた Markdown でも、画面が崩れず、文字を失わない (解釈できない部分は書かれたままの文字で出す)
- **S17 コードブロックが読みやすい**: DEN さんとして、応答の中のコードを、本文と見分けやすく、言語に応じて色分けされた形で読みたい
  - 受け入れ条件: コードブロックは、等幅の文字で、本文と区別できる背景の上に、字下げと改行をそのまま保って出す。長い行は、吹き出しからはみ出さない (横に送れるか、折り返す)
  - 受け入れ条件: 言語の指定が `typescript`・`ts`・`javascript`・`js`、`python`・`py`、`bash`・`sh`・`shell` のときは、キーワード・文字列・コメント・数値を簡単に色分けする
  - 受け入れ条件: 言語の指定が `markdown`・`md` のときは、中身を解釈せず原文のまま、ほかのコードブロックとは違う色で出す
  - 受け入れ条件: 言語の指定が無いとき、`plaintext`・`text` のとき、知らない言語のときは、色分けせず等幅の文字で出す
  - 受け入れ条件: コードブロックの中では、Markdown を解釈しない (`**` や `#` も書かれたまま)

## 3. 確かめ方

- 偽の応答役は直前の発言をそのまま応答に入れる (`fake reply #<n>: <直前の発言>`)。Markdown を書いて送れば、応答の吹き出しで装飾を確かめられる。自分の発言の吹き出しは装飾されないことも、同じ操作で確かめられる
- スクリプトのタグ、`javascript:` の URL、画像の書式、HTML のタグを含む発言を送り、応答の吹き出しでそれらがただの文字として出て、スクリプトが動かず、外部への通信が起きないことを確かめる (既存のホールドアウト H-38 も通り続ける)

## 4. Non-goals

- クリックできるリンク、画像の表示
- 表・引用・水平線・脚注・数式などの書式
- 上に挙げた以外の言語の色分け、本格的な構文解析による色分け
- コードブロックのコピーのボタン、色のテーマの切り替え
- 自分の発言の Markdown の解釈、入力欄でのプレビュー
- 外部の Markdown や色分けのライブラリ (CDN からの読み込みを含む)
